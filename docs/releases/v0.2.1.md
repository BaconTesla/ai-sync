# 第一版 · v0.2.1（开发预览）

这是用户确认符合当前需求的第一版，日常使用入口为 `main`。保留现有版本号 `0.2.1`，不将开发预览标为已签名的正式 macOS 发行版。

## 包含功能

- 通过 Tailscale IPv4 与配对令牌，在两台设备之间手动拉取。
- **只共享 Skills 与 MCP 服务定义**，不发送模型偏好、权限、历史、项目列表等其他 Agent 设置。
- Skills 以名称分组；点击后展示可展开 / 折叠的文件树，选择文件查看内容。
- 按整个 Skill 勾选有变化的可共享文件；相同文件不重写，本机独有文件不删除。
- MCP 只添加或替换同名服务，本机独有服务及其他设置值保留。
- 拉取前预览与二次确认；覆盖前备份；本机文件在预览后变化时拒绝写入。
- 路径白名单、符号链接拦截、大小限制及常见凭据的保守过滤。

## 保留的限制

- 尚未完成两台物理 Mac 的跨机验收，不保证在所有实际配置版本下兼容。
- 没有 DMG、应用签名或公证，仍需开发环境启动。
- 不自动同步、不执行 MCP / Skills、不支持删除同步。
- MCP 按来源文件内的服务组选择，暂不能逐个服务勾选。
- MCP 写回会调整排版，注释可能移除；保留其他设置值，原文先备份。遇到无法安全合并的 TOML 日期 / 时间等情况拒绝写入。
- 文件树只包含通过安全过滤的文本文件；被排除的依赖文件可能导致 Skill 不完整。
- 凭据过滤是启发式，不是完整密钥识别或独立安全审计。
- 多文件写入不是全局事务；备份恢复暂需手动操作。
- GUI 冒烟启动时可见 Chromium Shared Dictionary 缓存警告，但没有阻止本次测试断言执行。

## 获取与运行

两台设备都关闭旧版应用后，使用 `main`：

```sh
git clone --branch main https://github.com/BaconTesla/ai-sync.git
cd ai-sync
npm ci
npm start
```

已有仓库则在没有未提交修改时切换到 `main`，`git pull --ff-only` 后执行 `npm ci` 和 `npm start`。两端应使用相同版本，不使用已废弃的 v1 整文件同步协议。
