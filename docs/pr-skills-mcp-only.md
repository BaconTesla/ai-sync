# 只同步 Skills 和 MCP，不共享其他设置

Base: `feature/desktop-gui`（依赖尚未合并的 PR #2）

## 用户可感知的变化

- 界面只展示可共享的 Skills 与 MCP 定义，不再展示或传输完整 Agent 设置文件。
- MCP 同步只添加服务、替换同名服务，本机独有 MCP 服务及其他设置值保留。
- 同名服务是整条替换，包含 env / args 等；不做内部字段合并。
- 预览、确认和备份保留；MCP 来源文件会重新排版，注释可能移除，确认前明确提示。

## 隐私边界

- JSON / JSONC 只选顶层 `mcpServers` 或 `mcp`，Codex TOML 只选 `mcp_servers`。
- 模型、权限、历史、项目列表、非 MCP 密钥不进入共享快照。
- 拒绝包含其他顶层设置的远端 MCP 数据；源文件解析错误只返回通用提示，避免泄露解析器引用的原文。
- 常见凭据过滤仍作用于 Skill 文件 / MCP 服务组，过滤为启发式，并非密钥识别保证。
- 原始配置只在本机用于读取、合并、并发检查及完整备份，不发送给对端。
- 升级到 `/v2/snapshot`，拒绝 v1 快照，不请求旧版端点；两端必须更新并关闭旧版进程。

## 验证

- `npm run check` 通过。
- `npm test`：22 项通过。新增隐私隔离、JSONC / TOML 提取与合并、保留本机设置及独有服务、原文备份、私有设置并发修改中止、协议隔离等 12 项测试。
- `npm run test:smoke`：在独立临时目录及本机 Tailscale 地址完成 Skill + MCP GUI 预览、勾选、确认、拉取，验证本机模型偏好保留。
- `npm audit --audit-level=high` 未发现漏洞。
- GUI 冒烟测试不再使用日常实例的单实例锁，避免软件运行时测试悄悄退出却报告成功。
- Electron 冒烟启动时仍有 Chromium Shared Dictionary 缓存警告，未阻止 GUI 与网络断言执行；尚未进行两台物理设备跨机验收。

## 已知限制

- MCP 按来源文件中的服务组选择，暂不能逐个服务勾选。
- 写回重新序列化，不保证注释 / 格式保留；备份保留完整原文。
- TOML 日期 / 时间写回存在精度限制，遇到此类本机文件拒绝合并，不回退到整文件覆盖。
- 本次不执行 MCP、不自动同步、不删除本机独有服务。

## 合并建议

不要将 PR #2 的旧实现单独作为满足隐私范围限制的版本使用。可先将此 PR 合入 GUI 分支，再依次将核心 PR #1 和更新后的 GUI PR #2 集成到 `develop`，验收后再发布到 `main`。
